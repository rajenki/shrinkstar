ShrinkStar: XY Shrinkage Calibration

Shrinkage Calculator

Enter your caliper readings from the ShrinkStar test print. For the best results, ensure you have completed Flow Rate (Extrusion Multiplier) and Flow Dynamics (Pressure Advance) calibration before printing ShrinkStar.

ShrinkStar

Orient the print with the X arrow along your printer's X axis before slicing. Arm numbers 1 to 4 match the recessed digits on the print and the rows below.

Use calipers to measure each specified dimension 3 times and enter the measured values below. If the error % between measurements is too high, check that the correct dimension is being measured.

The calibration will result in a single Shrinkage % to paste into Bambu Studio → Filament Settings → Basic Information → Shrinkage. Complete this for each unique filament brand and type. Shrinkage should not vary much between filament colors of the same brand and type.
